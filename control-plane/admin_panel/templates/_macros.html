{# Shared building blocks. Imported, not extended: every list page needs the same toolbar, the same sortable header, the same pager, and duplicating that markup per table is how tables drift apart visually. #} {# --------------------------------------------------------------------------- Toolbar: live search + filters above a table. The whole thing is one GET form, so search works with JavaScript off: press the button (or Enter) and the page reloads filtered. The hx-* attributes are the enhancement, and they are all declared here on the form rather than duplicated onto each input: * `input changed delay:350ms from:[data-search]` — typing filters as you go. `changed` means the request only fires when the value actually differs from the last request, so backspacing and retyping the same string does not refetch. The 350ms delay is what makes this one request per pause instead of one per keystroke. * `change from:[data-filter]` — picking a status refilters immediately; there is no reason to make an operator press "apply" for a dropdown. * `submit` — the button and Enter, which is also the no-JS path. `hx-replace-url` rather than `hx-push-url`: a live search would otherwise push a history entry per paused keystroke, and the browser's back button would step through the operator's typing instead of leaving the page. The URL still reflects the search, so reloading and bookmarking keep it. The partial swaps `#rows` only, so the search box keeps focus and its caret position while results update underneath. --------------------------------------------------------------------------- #} {% macro toolbar(base_path, query, filters={}, placeholder="جست‌وجو…", result_id="rows") %}
